# 四阵元线阵角度、功率与通道误差边界报告

> 日期：2026-08-14<br>
> 记录与判断：Codex<br>
> 分支：`research/coherent-music-parking-array`

## 1. 这次实验回答什么

设备到货前，需要知道四阵元 ULA 在什么条件下值得进入实物验证。本轮不再零散改变多个
参数，而是在同一个北斗 B2a 基线上分别扫描：

1. 两源到达角之差 $\Delta\theta$；
2. 弱路相对强路的接收功率差 $\Delta P$；
3. 校准后仍残留的四通道相位误差；
4. 校准后仍残留的四通道增益误差。

本报告给出的都是**有前提的受控边界**，不是任意停车场、任意阵列朝向下的通用指标。

## 2. 共同实验条件

| 参数 | 设置 |
|---|---:|
| 信号 | 北斗 B2a pilot，PRN11 |
| 主码率 | 10.23 Mcps |
| 载频 | 1176.45 MHz |
| 阵列 | 四阵元 ULA，阵元间距 $0.5\lambda$ |
| 空间模型 | 精确球面波生成；理想阵列流形解算 |
| 两源距离 | 均为 20 m |
| 角度中心 | 270°，两源关于阵列宽侧方向对称 |
| 半平面先验 | 负 Y 半平面，消除 ULA 前后镜像二义性 |
| A 路实际 C/N0 | 45 dB-Hz |
| 有效时延差 | 15.6155 m，约 0.53 chip |
| 信号处理 | 100 ms B2a 复相关，FBSS-MUSIC 测角，复相关解混后估时延 |
| Monte Carlo | 每个条件 30 次，共 630 次 |

角度、功率、相位误差和增益误差每次只改变一个维度。通道误差在每个 run 中重新随机
生成；解算器仍使用理想流形，所以测到的是**未被校准消除的残余误差**对算法的影响。

## 3. 判据与公式

两路角度真值为 $\theta_0,\theta_1$，匹配后的估计为
$\hat\theta_0,\hat\theta_1$。角度均方根误差为：

$$
\operatorname{RMSE}_{\theta}
=\sqrt{\frac{1}{2}\sum_{i=0}^{1}
\left[\operatorname{wrap}_{180}(\hat\theta_i-\theta_i)\right]^2}.
$$

本轮使用两个不同层次的成功判据：

$$
\text{DOA 双峰成功}
\iff
\max_i\left|\operatorname{wrap}_{180}(\hat\theta_i-\theta_i)\right|
\le 5^\circ,
$$

$$
\text{完整双源成功}
\iff
\text{DOA 双峰成功}
\land
\left|\widehat{\Delta d}-\Delta d\right|\le 10\ \mathrm{m}.
$$

若空间谱只有一个局部峰，则状态明确记为 `UNRESOLVED_ONE_PEAK`，不会从同一个宽峰上
强行挑两个网格点。为公平测试 5° 条件，判峰器允许两个局部峰最小相隔 2°；这个参数
小于最小被测角差，不会在代码层面预先否决 5° 双源。

成功率同时报告 Wilson 95% 区间。对 $n$ 次实验中成功 $k$ 次，记
$\hat p=k/n$、$z=1.96$，区间中心为：

$$
c=\frac{\hat p+z^2/(2n)}{1+z^2/n},
$$

半宽为：

$$
h=\frac{z}{1+z^2/n}
\sqrt{\frac{\hat p(1-\hat p)}{n}+\frac{z^2}{4n^2}}.
$$

## 4. 实验结果

### 4.1 两源角度差

| $\Delta\theta$ | DOA 双峰 | 完整双源 | 单峰次数 | 角 RMSE 中位数 / p95 |
|---:|---:|---:|---:|---:|
| 90° | 30/30 | 30/30 | 0 | 0.35° / 0.79° |
| 60° | 30/30 | 30/30 | 0 | 0.35° / 0.71° |
| 40° | 30/30 | 30/30 | 0 | 0.35° / 0.71° |
| 30° | 30/30 | 30/30 | 0 | 0.35° / 0.50° |
| 20° | 30/30 | 30/30 | 0 | 0.71° / 1.06° |
| 10° | 29/30 | 29/30 | 0 | 1.06° / 2.49° |
| 5° | 18/30 | 11/30 | 7 | 2.57° / 5.67°（仅双峰样本） |

5°处不仅 DOA 退化，空间解混后的时延也退化：18 次 DOA 合格中仅 11 次同时满足
时延误差门限。这是当前四阵元 ULA 的明显过渡区。

### 4.2 弱路接收功率差

固定 $\Delta\theta=60^\circ$。A 路实际 C/N0 为 45 dB-Hz，因此 B 路在各条件下约为
45、42、39、35 和 30 dB-Hz。

| B/A 接收功率差 | DOA 双峰 | 完整双源 | 角 RMSE 中位数 / p95 |
|---:|---:|---:|---:|
| 0 dB | 30/30 | 30/30 | 0.35° / 0.75° |
| -3 dB | 30/30 | 30/30 | 0.35° / 0.94° |
| -6 dB | 30/30 | 30/30 | 0.71° / 1.41° |
| -10 dB | 30/30 | 30/30 | 1.29° / 2.86° |
| -15 dB | 18/30 | 18/30 | 2.31° / 6.91° |

在本基线下，-10 dB 尚未出现失败，-15 dB 已明显进入临界区。这里的 $\Delta P$ 是
**接收端实际功率差**，不能直接用模拟器面板上的发射功率差替代。

### 4.3 通道相位残差

| 配置相位误差 RMS | DOA 双峰 | 完整双源 | 角 RMSE 中位数 / p95 |
|---:|---:|---:|---:|
| 0° | 30/30 | 30/30 | 0.35° / 0.75° |
| 1° | 30/30 | 30/30 | 0.35° / 1.06° |
| 3° | 30/30 | 30/30 | 0.75° / 2.09° |
| 5° | 29/30 | 29/30 | 1.90° / 3.61° |
| 10° | 23/30 | 23/30 | 2.49° / 6.06° |

相位残差比同量级的增益残差更危险。3°以内在 30 次预扫中全部通过；5°开始出现
失败，10°已不能作为可靠工作区。

### 4.4 通道增益残差

| 配置增益误差 RMS | DOA 双峰 | 完整双源 | 角 RMSE 中位数 / p95 |
|---:|---:|---:|---:|
| 0 dB | 30/30 | 30/30 | 0.35° / 0.71° |
| 0.2 dB | 30/30 | 30/30 | 0.35° / 0.71° |
| 0.5 dB | 30/30 | 30/30 | 0.35° / 0.94° |
| 1.0 dB | 30/30 | 30/30 | 0.35° / 1.06° |

本轮只证明增益残差到 1 dB 尚未构成瓶颈，**没有找到最大容忍边界**，不能把 1 dB
误写成极限。

## 5. 对天线制作和实物布置的直接结论

在本报告的共同条件下，可采用下面三档工程口径：

| 项目 | 首轮实物目标 | 压力测试区 | 当前不宜依赖 |
|---|---:|---:|---:|
| 两源角度差 | $\ge 20^\circ$ | 约 10° | 5° |
| B/A 接收功率差 | $\ge -10$ dB | -10 至 -15 dB之间 | -15 dB |
| 校准后相位残差 RMS | $\le 3^\circ$ | 约 5° | 10° |
| 校准后增益残差 RMS | $\le 1$ dB | 尚未找到边界 | 未测试 $>1$ dB |

选择 $20^\circ$ 而不是 $10^\circ$ 作为首轮布置目标，是因为 10°虽然达到 29/30，
但 30 次样本下 Wilson 95% 下界只有 83.3%，尚不足以证明 90%可靠性。20°是本次预扫
中仍保有明显角误差余量的最小网格点。

这组结论还依赖以下前提：阵列朝向使两源位于宽侧附近；接收机所在半平面已知；两源
均距阵列中心 20 m；A 路为 45 dB-Hz；时延差约 0.53 chip；使用精确球面波生成但理想
流形解算。ULA 对阵列端射方向和前后镜像的限制并未因此消失。
